# Camera Simple

A simple camera app for the Mac.

## Why

Every Mac has a camera app, Photo Booth, but its name makes it hard to find when you want the camera.

Camera Simple is named for what it does. Press Command + Space, type "camera", press Return, and it opens to a live mirror and a shutter button.

## Features

- Live, mirrored camera preview
- Take a photo with the shutter button or the Space key
- Choose the folder photos are saved to
- Switch between cameras, including external ones
- Zoom in and out
- Aspect ratios: Full (the camera's own shape, the default), 16:9, 1:1, 9:16; the window keeps the picture's shape

## Install

Download the DMG from the [latest release](https://github.com/ddfzhh/camera-simple/releases/latest), open it, and drag Camera Simple to Applications.

Or with [Homebrew](https://brew.sh):

```bash
brew install --cask ddfzhh/tap/camera-simple
```

Works on Apple Silicon and Intel Macs with macOS 12 or later.
